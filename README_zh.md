# FiDeR / SSRL 核心代码包

这是论文使用的主要算法代码，另附两波段模拟和真实观测的固定小样例。它可以独立运行，不需要原来约 18 GB 的母工程。

英文 README 给出了安装命令。安装后，依次运行 `tests` 中的检查、`examples/replay_simulation.py` 和 `examples/replay_real.py`。正常运行会打印与存档结果的误差；超过预设容差会直接报错。

代码分成两组：

1. `simulation_*` 保留原模拟中的 FiDeR、RL 和 SSRL 核心函数。
2. `real_fider.py`、`masked_backend.py` 等保留真实观测的局部掩膜扩展。论文中的 SSRL* 指这一组，不是完整 UPDC 多曝光软件。

FiDeR 预滤波先做内部 1000 步；然后 RL 或 SSRL 做最终 40 步。不要把它们合成一个“1040 步反卷积”。SSRL 的负值和零值不会被改成正值；坏像素也不会被当成亮度为零的有效观测。

真实样例内已提供背景、有效计数换算、星心、PSF 和独立访问叠加图。该代码包不自动下载 FITS、不重拟合 PSF，也不一键重跑整篇论文的全部模拟。例子展示的是算法调用及存档回放。原始来源与逐函数对应见 `PROVENANCE.json`；核查结果见 `docs/validation.json`。

本文件所在目录的内容可直接作为仓库根目录，不要只上传 ZIP 压缩包，也不要上传整个母工程。论文中的仓库地址应指向经核查、可供读者访问的实际仓库。
